The reading room

Guides

Four short guides on the problems a11ymedic finds most often: what each rule means, who it helps and the code that fixes it.

  • Guide

    Fixing color contrast and keeping your brand colors

    The WCAG contrast ratios, the traps that hide failing text, and how to pick a passing color close to the one you have.
  • Guide

    Writing alt text for every kind of image

    When to describe an image and when to leave alt empty, with examples for links, buttons, icons, charts and SVG.
  • Guide

    Labeling form fields

    Visible labels, groups of options, hints and errors, and autocomplete for every kind of form field.
  • Guide

    Running accessibility checks in CI

    Fail a build on serious problems, get annotations on pull requests, and test components with Vitest or Jest.
  • Cheat sheet

    WCAG 2.2 cheat sheet in plain language

    Every A and AA success criterion in one or two sentences, with the a11ymedic rules that check it.

An accessibility checker that explains every problem in plain language and writes the exact fix. Free and open source under the MIT license.

Built with Monsoon. Interactive parts built with Voodoo.js.
